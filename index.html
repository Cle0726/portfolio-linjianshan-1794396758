一点做事的方式。

设计不是把东西变好看，
是让人不用想就懂。

我叫林见山，做视觉设计第七年。先在出版社排了三年书，后来去品牌工作室，现在独立接活。习惯从内容本身找形式：一本书的节奏、一间店的位置、一组数据里被忽略的规律。

合作方式通常是先聊清楚要解决什么，再动手。小到一张海报，大到一套系统，都按这个顺序来。

  • 专注品牌识别 / 编辑设计 / 信息设计也做导视、书籍与展览平面
  • 常驻杭州，可远程协作客户分布在上海、成都与东京
  • 工具InDesign / Illustrator / Figma也手写一点 CSS 做网页原型
